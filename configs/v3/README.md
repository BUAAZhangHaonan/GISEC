# GISEC v3 Config Surface

This directory is reserved for the `GISEC v3-alpha` object-first line.

## Current Defaults

- `UQ-s`
- `UQ-m`
- `ResNet` encoder family only
- `RGB + depth geometry` early fusion only

## Legacy Boundary

Legacy names such as `A0`, `A1`, `Q0`, `Q1`, `Q2`, `B0`, and `G*` remain historical/debug-only identifiers and must not be reused as `v3-alpha` model ids.
