# GISEC Query Config Surface

This directory is reserved for the `GISEC Query Alpha` object-first line.

## Current Defaults

- `UQ-s`
- `UQ-m`
- `ResNet` encoder family only
- `early6` fusion only: `RGB + depth geometry`

## Legacy Boundary

Legacy names such as `A0`, `A1`, `Q0`, `Q1`, `Q2`, `B0`, and `G*` remain historical/debug-only identifiers and must not be reused as `query-alpha` model ids.
