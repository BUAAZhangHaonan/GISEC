# GISEC Method Notes

This directory holds human-written descriptions of the method as it stabilizes.

## Intended Contents

- model and data-flow overviews
- prototype-bank contract notes
- graph-refiner interface notes
- bridge notes for the later MagFormer integration
- [`gisec-v2-method.md`](gisec-v2-method.md) for the planned `GISEC v2` method definition

These files should stay synchronized with the implementation in `gisec/`.

## Current Status

- `GISEC v1 / Stage 1 baseline` is the currently implemented line.
- `GISEC v2` is currently a design and planning target, documented before implementation to avoid mixing historical `B0/G1/G2/G3/G4/G5` semantics with the new `A0-A6` family.
